# 使用指南

[返回项目首页](../README.md)

余量 · Quotile 用于查看 **Codex 额度**。最低支持 Android 12（API 31），重点适配三星 Galaxy Z Fold7；无需电脑、服务器、Termux 或 API Key。

## 安装与升级

1. 用手机打开[Quotile-0.3.6.apk](../downloads/Quotile-0.3.6.apk?raw=true)，下载 APK。若 GitHub 显示文件详情页，点击下载按钮。
2. 打开下载的文件。若系统提示未允许此来源安装应用，只需按提示为本次使用的浏览器或文件管理器开启安装权限。
3. 安装后，在应用列表打开「余量」。

| 已安装版本 | 升级方式 |
| --- | --- |
| 本项目交付的 0.3.0–0.3.5 | 直接安装 0.3.6 覆盖升级，保留登录、设置与小组件。覆盖安装后，若桌面未即时重绘，点一次刷新即可。 |
| 0.2.0 | 旧版使用一次性调试签名，需先卸载，再安装新版、重新登录并添加小组件。卸载会清除本地数据。 |
| 自行构建或 GitHub Actions 调试版 | 签名可能不同，不能保证直接覆盖。请使用相同签名的版本更新；如确需改装交付版，应先确认并接受卸载会清除数据。 |

本仓库的 `downloads/Quotile-0.3.6.apk` 使用固定交付签名，区别于 Actions 中的调试 APK。可选校验信息：

```text
APK SHA-256
d0002c001ece9f92d14e6ef58b5fd892c37aec1aa8531e6ee7bbc89278f40736

签名证书 SHA-256
d2cb32c3211f1d587e5900d646222a7aca046142cb0eb99adb0eb5f7f1f26079
```

## 首次登录

建议先尝试**设备码登录**；这条方式已在 Galaxy Z Fold7 上成功使用，不依赖浏览器回跳手机的 `localhost` 地址。

1. 确认账户允许设备码登录。如官方页面提示未启用，请在 ChatGPT 的安全设置中启用对应选项；账号或工作空间没有该选项时，使用下方浏览器方式。
2. 在「余量」点击 **「设备码登录 · 网页卡住时使用」**。
3. 按应用提示打开 `auth.openai.com` 的官方授权页面，输入本次显示的短时验证码，并完成授权确认。验证码仅用于你主动发起的这次登录，不要交给其他人。
4. 返回「余量」，等待状态变为已登录，然后点击 **「刷新额度」**。

设备码登录最多等待 15 分钟，可在应用中取消。等待期间会短时轮询授权结果，成功、取消或超时后结束。若超时，重新发起一次登录并使用新验证码。

也可以点击 **「登录 ChatGPT」**，在系统浏览器的 OpenAI 官方页面完成登录与授权，再返回应用。这一方式使用 OAuth PKCE，并等待手机本地回调，最多 3 分钟。超时后旧授权页面对应的会话已经结束，需要重新发起。

应用不要求填写密码、Cookie 或 API Key；账户密码只应在官方页面输入。登录状态加密保存在手机上，**登录完成不会自动读取额度**。

## 添加和调整小组件

1. 在应用中点击「添加 1 × 5」或「添加 2 × 5」，按启动器提示确认添加。
2. 也可以长按桌面空白处，打开「小组件」，找到「余量」，选择样式后放到桌面。
3. 如出现设置页，完成设置后点击「保存并完成添加」。
4. 长按桌面小组件，拖动边缘调整宽度和高度。

本项目的尺寸顺序是 **高 × 宽**。某些启动器按宽 × 高标注，因此会显示为 5×1 和 5×2。

| 布局 | 显示内容 |
| --- | --- |
| 一行紧凑卡片 | 每周余量、进度条、重置时间和更新时间；刷新或旧数据状态会占用底部提示位置。 |
| 两行及以上，每周单栏 | 每周余量、重置时间、账户可用重置次数；次数大于 0 时，次数下方增加最近到期时间。 |
| 两行及以上，双栏 | 接口返回 5 小时额度且宽度足够时，自动增加 5 小时余量和对应重置时间；可用重置次数和最近到期时间仍为账户共用的一组。 |

卡片根据启动器给出的实际尺寸重新排版：高度达到 **110dp** 时启用详细布局；宽度达到 **250dp** 且有 5 小时数据时显示双栏。支持的布局范围为宽 110–700dp、高 40–300dp。实际占格随 One UI 网格、内外屏、显示缩放和字体大小变化。

在「显示与刷新」中选择浅色、深色或跟随系统，再点击 **「保存设置」**。若只想看外观，可以开启「演示模式」并保存；桌面会标注「演示」，其中数字不代表真实账户。

## 手动与自动刷新

**默认关闭自动刷新。** 第一次登录后，在应用里点击「刷新额度」；放到桌面后，点小组件右侧刷新按钮即可原地更新，不会打开应用窗口。点卡片的其他区域会进入设置。

需要定时更新时，在「显示与刷新」中开启 **「自动刷新」**，选择 15、30 或 60 分钟。开关和间隔调整立即生效，不需要再点保存。Android 会根据系统调度、休眠、省电和网络情况执行，因此这些是近似间隔，并非精确闹钟。

关闭开关会取消已安排的定时任务，并请求终止进行中的自动读取。应用没有常驻服务；关闭自动刷新时，打开应用、保存外观、添加或缩放小组件都只使用本地数据，不额外查询额度。主动登录期间的短时授权轮询独立于额度刷新。

令牌到期后，会在下一次手动读取或已开启的自动任务中尝试续期；如果登录失效，应用会提示重新登录。

## 如何理解卡片内容

| 显示 | 含义 |
| --- | --- |
| 每周剩余 / 5 小时剩余 | 上次成功读取时，Codex 对应额度窗口的剩余百分比。未返回的额度项不补算。 |
| `今天 HH:mm 重置` / `M/d HH:mm 重置` | 接口给出的该额度窗口重置时间，以北京时间显示。 |
| `可用重置 N 次` | 接口明确给出的当前可用次数；账户共用，只展示，不执行兑换或消耗。 |
| `可用重置 —` | 接口未提供有效次数，或当前仍是升级前的旧快照。可先手动刷新；仍为「—」不等于 0 次。 |
| `0 次` | 接口明确返回可用次数为 0；下方不显示到期信息。 |
| `最近到期 M/d HH:mm` | 当前可用重置机会中，最近一次到期的时间，统一为北京时间。与上方额度窗口的自动重置时间含义不同。 |
| `到期时间未提供` | 有可用重置机会，但接口没有提供足够完整、有效的明细，或明细查询失败，暂时无法确认最近到期时间。 |
| `旧数据 · 点击刷新` | 读取失败或已越过缓存中的重置时间；画面保留上次结果，不能视为最新余量。 |
| `已到期 · 待刷新` | 已到上次记录的重置时间，需要重新读取才能确认当前额度。 |
| `M/d HH:mm 更新 · 北京时间` | 最近一次成功读取的时间，不是实时推送，也不会自行变成当前时间。 |
| `演示` / `演示数据` | 合成数据，仅供试外观。关闭演示并保存，才能查看已读取的账户结果。 |

两行卡片会优先保留重置时间、次数和适用的到期信息，并按可用空间将更新时间或「刷新中／旧数据／演示」合并在次数后方；拉高卡片可显示独立更新时间。次数为 0 或未知时，不显示到期信息行；一行紧凑卡片也不增加这一行。

可用次数来自 `rate_limit_reset_credits.available_count`，它不是累计获得次数、充值余额或历史列表数量。次数本身随余量返回；只有次数大于 0 时，才会在这次刷新中附加查询重置机会明细。最近到期时间只从完整、有效的可用明细确定；缺失或截断的列表不会被用来推算次数或猜测期限。明细查询失败不会丢掉这次成功读取的主要额度。Quotile 不提供执行重置的按钮，也不会消耗机会。

已保存的到期时间过去后，卡片重绘时会标明旧数据、等待刷新，不会据此自行扣减次数或发起请求。自动刷新关闭时，请点击刷新按钮确认当前状态。

这里的数据属于 **Codex**，不能据此判断全部 ChatGPT 模型、对话与工具的可用额度，也不是 API 账单或余额。不同账号返回的字段可能不同。

## 常见问题

### 官方授权页一直转圈，返回应用仍在等待

先在应用中取消当前登录，再尝试「设备码登录 · 网页卡住时使用」。设备码方式不依赖浏览器回跳本地地址，但仍需官方账户允许这类授权。如果两种方式都失败，请检查是否能正常访问官方登录页，并保留应用显示的错误提示。

浏览器页面转圈本身不能确定是网络、账号、官方服务还是回调环节导致。浏览器方式 3 分钟超时后，需要重新发起，不能继续使用旧页面完成已结束的会话。

### 登录成功后没有额度

先点击「刷新额度」；登录不会自动查询。若仍无数据，检查是否开启了演示模式、是否收到登录失效或接口不可用提示。接口没有提供的额度不会被推算出来，部分账号可能没有相应额度窗口。

### 没有 5 小时栏，或者重置次数一直是「—」

5 小时栏需要接口实际提供该项，并且小组件达到详细布局所需的高度与宽度。次数是可选字段，接口未返回时显示「—」属于预期行为；不会根据 Pro 套餐名称补成某个数字。

### 开了自动刷新，时间却没有按点更新

自动刷新使用系统任务调度，省电、休眠或网络状态会延迟执行。可先点右侧刷新按钮确认手动读取是否正常，再检查系统对「余量」的后台和电池设置。失败时会保留旧数据与原更新时间。

### 小组件文字拥挤，或者内外屏大小不一致

长按小组件稍微拉宽或拉高，并查看 One UI 的桌面网格和系统字体、显示缩放。布局使用原生控件，实际可用空间由启动器决定；两行详细卡片需要至少 110dp 高度，双栏还需要至少 250dp 宽度。

### 如何清除本机登录

在应用中点击「退出登录」，清除本机登录状态和已保存的额度记录。网络请求和数据保存方式见[隐私说明](../PRIVACY.md)。

如果仍需帮助，可在 [Issues](https://github.com/MicHrrrD/quotile/issues) 提供机型、Android／One UI 版本、Quotile 版本、复现步骤和脱敏截图。不要上传密码、设备验证码、访问令牌、Cookie 或签名文件。

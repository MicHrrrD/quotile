# 余量 · Quotile

三星 Galaxy Z Fold7 桌面额度小组件。0.2.0 改为**手机本地登录、手动刷新与可关闭的自动刷新**，不需要电脑、服务器或 Termux。

这是独立开发的本地接入测试版。接口根据 OpenAI 开源 Codex 客户端适配，并非官方 Android SDK；真实登录和额度读取仍需在本人手机上确认。

## 使用

1. 安装 `Quotile-0.2.0.apk`，打开「余量」。不同云构建的调试签名可能不同；若覆盖安装提示签名不一致，需要卸载旧版再安装，旧设置会清除。
2. 点击「登录 ChatGPT」，在系统浏览器的 `auth.openai.com` 官方页面完成登录，然后返回应用。登录状态加密保存在手机，不需要填写服务地址、配对码或 API Key。
3. **默认关闭自动刷新。** 此时点击「刷新额度」才读取数据，登录成功不自动查询。
4. 点击「添加 1×5」或「添加 2×5」，长按桌面上的小组件拖动边缘调整尺寸；也可从 One UI 的小组件列表添加。
5. 之后点击小组件右侧刷新按钮，会显示一个短暂的读取窗口，完成后更新桌面。也可在设置中打开「自动刷新」，选择 15／30／60 分钟；开关和间隔调整立即生效。

可先开启「演示模式」并保存来试外观。所有示例均标注「演示」，不能当作真实账户额度。

## 刷新控制

- 自动刷新默认关闭；关闭时不保留定时任务，已安排任务会取消，正在进行的自动读取也会请求终止。
- 主动开启后，由系统 JobScheduler 按所选间隔安排任务；省电、休眠、网络情况可能延迟执行。没有常驻服务。
- 打开应用、保存外观、添加或缩放小组件不会额外查询额度；已主动开启的自动刷新按原设置运行。
- 登录由「登录 ChatGPT」按钮单独发起；OAuth 令牌到期后，在下一次手动读取或已开启的自动任务中尝试续期。
- 读取失败保留上次结果和原时间，不猜测余量，也不在重置时自动填成 100%。
- 升级会取消 0.1.0 的历史任务；系统可能要求应用重绘组件，但重绘不会发起额度查询。
- 读取时间使用北京时间的绝对日期与时间，避免“刚刚更新”长时间冻结造成误解。

## 尺寸与显示

所有尺寸采用**高 × 宽**；启动器可能以宽 × 高显示为 5×1 / 5×2。

| 尺寸 | 内容 |
| --- | --- |
| 1×5 | 周剩余百分比、细进度条、重置时间、上次读取时间 |
| 2×5 | 更详细的周额度；来源实际返回五小时项时显示双栏 |
| 缩窄 / 放大 | 根据实际 dp 尺寸重新排版，支持宽 110–700dp、高 40–300dp |

支持浅色、深色和跟随系统。内外屏占格取决于 One UI 网格与显示缩放。Canvas 卡片文字不等同于原生 TextView 的系统字体缩放行为。

## 额度含义与登录

目前读取的是 **Codex 额度桶**。不能未经实际账户核对，将它等同于所有 ChatGPT 对话、模型和工具的 Pro 周限额。应用明确显示来源；官方没返回的项保持未知，`pro` 不会被擅自补成 `Pro 5x`。

本地客户端依据 [OpenAI Codex rust-v0.153.4](https://github.com/openai/codex/tree/rust-v0.153.4) 的公开原生 OAuth 客户端流程与额度读取代码，实现 PKCE/state、短时回环回调、Android 系统 HTTPS，以及 Android Keystore AES-GCM 凭据存储。它使用独立的应用标识和较少的授权范围。第三方 Android 登录、较少授权范围和后端端点的实际兼容性，需要本人登录验证；上游变化可能需要更新应用。

应用不会读取 ChatGPT App 的私有文件，不要求 Root，不收集密码或 Cookie，不把登录状态提交到 GitHub。云端只编译源码并用合成数据测试，不持有用户账号。

## 构建与验证

[GitHub Actions](https://github.com/MicHrrrD/quotile/actions) 在推送 main / mobile-local 或手动触发时构建。使用 JDK17、Gradle8.11.1、AGP8.10.1、SDK36、BuildTools35.0.0。

```sh
python tools/verify_source.py
python tools/build_android.py
```

工作流会验证 APK 签名，并在 Android16 模拟器上检查缓存行为、无定时任务、额度解析、OAuth 回调验证、加密存储和多个卡片尺寸。测试不用真实账号。测试包括默认关闭与关闭任务的行为；当前完成情况见 `VALIDATION.md`；通过这些检查不代表已通过 Fold7 实机登录验证。

`bridge/` 保留 0.1.0 的服务端源码，0.2.0 手机版本不依赖它。

Quotile 与 OpenAI 或三星没有官方隶属关系。

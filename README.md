# 余量 · Quotile

三星 Galaxy Z Fold7 桌面额度小组件。支持**手机本地登录、手动刷新与可关闭的自动刷新**，不需要电脑、服务器或 Termux。

用户已在 Galaxy Z Fold7 上确认 0.2.0 可正常登录、运行并读取真实额度，也已确认 0.3.1 的设备码登录成功。0.3.2 保留现有外观与登录流程，只调整底部文字空间，避免裁切，并增加 GPT 图标和「Codex 额度」来源标注。

## 使用

1. 安装 `Quotile-0.3.2.apk`，打开「余量」。从已交付的 0.3.0 / 0.3.1 升级可直接覆盖安装，保留设置和已有登录状态，无需重新登录。0.3.0 起沿用同一份私下保管的固定发布签名；仅 0.2.0 的一次性调试签名不兼容，需要先卸载、重新登录并添加组件。
2. 点击「登录 ChatGPT」，在系统浏览器的 `auth.openai.com` 官方页面完成登录，然后返回应用。如果浏览器授权反复超时，可改用设备码登录，操作见下文。登录状态加密保存在手机，不需要填写服务地址或 API Key。
3. **默认关闭自动刷新。** 此时点击「刷新额度」才读取数据，登录成功不自动查询。
4. 点击「添加 1×5」或「添加 2×5」，长按桌面上的小组件拖动边缘调整尺寸；也可从 One UI 的小组件列表添加。
5. 之后点击小组件右侧刷新按钮，直接在桌面显示刷新状态并更新结果，不打开应用窗口。点击卡片其余区域仍可进入设置。也可在设置中打开「自动刷新」，选择 15／30／60 分钟；开关和间隔调整立即生效。

可先开启「演示模式」并保存来试外观。所有示例均标注「演示」，不能当作真实账户额度。

## 刷新控制

- 自动刷新默认关闭；关闭时不保留定时任务，已安排任务会取消，正在进行的自动读取也会请求终止。
- 主动开启后，由系统 JobScheduler 按所选间隔安排任务；省电、休眠、网络情况可能延迟执行。没有常驻服务。
- 打开应用、保存外观、添加或缩放小组件不会额外查询额度；已主动开启的自动刷新按原设置运行。
- 登录仅由用户主动发起；设备码登录只在当前登录会话内短时轮询授权结果，完成、取消或超时后结束，最多等待 15 分钟。登录成功不自动查询额度。OAuth 令牌到期后，在下一次手动读取或已开启的自动任务中尝试续期。
- 读取失败保留上次结果和原时间，不猜测余量，也不在重置时自动填成 100%。
- 升级会取消 0.1.0 的历史任务；系统可能要求应用重绘组件，但重绘不会发起额度查询。
- 读取时间使用北京时间的绝对日期与时间，避免“刚刚更新”长时间冻结造成误解。

## 尺寸与显示

所有尺寸采用**高 × 宽**；启动器可能以宽 × 高显示为 5×1 / 5×2。

| 尺寸 | 内容 |
| --- | --- |
| 1×5 | 周剩余百分比、胶囊进度条、重置时间、上次读取时间 |
| 2×5 | 更详细的周额度；来源实际返回五小时项时显示双栏 |
| 缩窄 / 放大 | 根据实际 dp 尺寸重新排版，支持宽 110–700dp、高 40–300dp |

支持浅色、深色和跟随系统。浅色为柔白背景 #F7F7F8、近黑文字 #181818，加粗并上移的胶囊进度条。桌面使用原生 TextView、ProgressBar 和矢量图标，不再拉伸整张卡片位图；窄尺寸会缩短信息并自动适配文字。内外屏占格取决于 One UI 网格与显示缩放。

## 额度含义与登录

目前读取的是 **Codex 额度桶**。不能未经实际账户核对，将它等同于所有 ChatGPT 对话、模型和工具的 Pro 周限额。应用明确显示来源；官方没返回的项保持未知，`pro` 不会被擅自补成 `Pro 5x`。

本地客户端依据 [OpenAI Codex rust-v0.153.4](https://github.com/openai/codex/tree/rust-v0.153.4) 的公开原生 OAuth 客户端流程与额度读取代码，实现 PKCE/state、短时回环回调、Android 系统 HTTPS，以及 Android Keystore AES-GCM 凭据存储。浏览器登录沿用独立的应用标识和较少的授权范围；设备码方式遵循上游设备授权流程，不另行指定浏览器授权范围。第三方 Android 登录和后端端点的实际兼容性，需要本人登录验证；上游变化可能需要更新应用。

浏览器登录从发起时起最多等待 3 分钟。应用会显示当前等待阶段；超时后需重新发起，旧授权页面不能继续完成已经结束的会话。官方授权页一直转圈并不能单独证明是本机回调、网络或上游服务中的哪一环故障。

备用设备码登录使用 [OpenAI 官方设备码授权流程](https://learn.chatgpt.com/docs/auth)，不需要浏览器跳回手机的 localhost 地址：

1. 在 ChatGPT 的安全设置中启用设备码登录；若账号或工作空间未开放此选项，仍需使用浏览器登录。
2. 在「余量」主动发起设备码登录，取得本次显示的短时验证码。
3. 按应用提示打开 `auth.openai.com` 的官方授权页面，输入本次验证码并完成确认，然后返回「余量」。请勿把验证码提供给他人。
4. 授权成功后，仍需点击「刷新额度」才读取数据。需要中止时，可在应用内取消；超过最长 15 分钟会结束本次等待。

设备码登录提供另一条授权方式，并不保证绕过官方账号限制或解决所有授权页故障。

应用不会读取 ChatGPT App 的私有文件，不要求 Root，不收集密码或 Cookie，不把登录状态提交到 GitHub。云端只编译源码并用合成数据测试，不持有用户账号。

## 构建与验证

[GitHub Actions](https://github.com/MicHrrrD/quotile/actions) 在推送 main / mobile-local 或手动触发时构建。使用 JDK17、Gradle8.11.1、AGP8.10.1、SDK36、BuildTools35.0.0。

```sh
python tools/verify_source.py
python tools/build_android.py
```

工作流验证 APK 签名，并在 Android16 上检查默认关闭、取消任务、桌面广播不启动 Activity、额度解析及加密存储。卡片在原生 Android 控件上渲染，截图随构建产物提供。[0.3.2 构建与 Android16 检查已通过](https://github.com/MicHrrrD/quotile/actions/runs/33962762493)，包括新增的 13 个底注、字体缩放和 Codex 来源标记布局用例。签名与安装包校验值见 `VALIDATION.md`。云端测试使用合成数据；用户另已确认 0.3.1 在手机上完成设备码登录。

Actions 产物包含测试用调试 APK 和 Android 官方签名工具；最终交付使用 `tools/sign_apk.py` 在本地重签，验证证书与全部应用内容未变。签名私钥和口令不进入源码仓库。

`bridge/` 保留 0.1.0 的服务端源码，当前手机版本不依赖它。

Quotile 与 OpenAI 或三星没有官方隶属关系。
